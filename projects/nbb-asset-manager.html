NBB Asset Manager

A Blender addon that gives artists a proper asset library — browse, create, version and publish — without a database. The folder tree is the database. Try the live demo below.

PythonBlender 4.2+bpyZero-DB design

What it does

Every asset lives in a conventional folder: Assets / Type / Asset / work · publish · review. Artists work in work, and when a version is approved it gets promoted to publish — same number, blessed copy. The addon scans that tree and puts it one click away inside Blender: scan the project, create a new asset, open any version, save the next one, publish the approved one.

Under the hood

Filesystem as truth

No database, no daemon. A folder convention plus a version regex is the whole schema — anything can read it, nothing can corrupt it.

Swappable backend

All data flows through a 5-method provider interface. Pointing the same UI at ShotGrid later means writing one new class, nothing else changes.

Fail-fast config

Layered TOML settings merge package defaults with per-studio overrides — and a missing or broken config raises loudly instead of silently degrading.
